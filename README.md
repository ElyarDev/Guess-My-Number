# 🔢 Guess My Number!

A fun and interactive number guessing game built with **HTML, CSS, and Vanilla JavaScript**. Test your guessing skills, find the secret number between 1 and 20, and try to achieve the highest score!

## 🚀 Live Demo

[**Play Guess My Number!**](https://elyardev.github.io/Guess-My-Number/)

## 📸 Preview

An interactive number guessing game featuring a clean interface, real-time feedback, score tracking, and a high score system.

## ✨ Features

- 🎯 Random secret number generation
- 🔢 Number guessing between 1 and 20
- 💬 Dynamic feedback for each guess
- 📊 Real-time score tracking
- 🏆 High score system to save your best result
- 🔄 Restart functionality with the Again button
- 🎨 Clean and user-friendly interface
- ⚡ Interactive gameplay powered by JavaScript

## 🎮 How to Play

1. A random secret number is generated between **1 and 20**.
2. Enter your guess in the input field.
3. Click the **Check!** button to submit your guess.
4. Receive hints to find out whether your guess is too high or too low.
5. Each incorrect guess decreases your score.
6. Guess the correct number before your score reaches zero!
7. Click **Again!** to start a new game and try to beat your high score.

## 🛠️ Technologies Used

- **HTML5** – Structuring the game interface.
- **CSS4** – Styling and designing the user interface.
- **JavaScript (ES6+)** – Random number generation, DOM manipulation, event handling, and game logic.
